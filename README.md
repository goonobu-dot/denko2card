# 電工二種 暗記カード - 器具鑑別と複線図

第二種電気工事士（学科試験）対策の暗記カードアプリ。「器具・材料の鑑別」「図記号・複線図」「法令・理論」の3科目、計340枚のカードを、段階ヒント（図解 → 語呂 → 3択）と間隔反復（忘却曲線に基づく復習スケジューリング）で反復学習できる。

総合過去問アプリとは戦わず、**器具鑑別・図記号・複線図**という第二種電気工事士に特有の出題領域に絞って作り込んでいる。

## 特徴

- **段階ヒント方式**: 図解 → 語呂合わせ → 3択、の順にヒントレベルを上げながら想起練習する
- **間隔反復**: FSRS簡易スケジューラで、カードごとに次回復習日を自動調整
- **オフライン完結**: アカウント登録不要、広告なし、データ収集なし
- **買い切り課金**: 月額サブスクは作らず、`¥1,800`の買い切りのみ（`com.goonobu.denko2card.unlock`）
- **無料枠**: 最初の2トピック（電線・ケーブル、工具＝計40枚）＋1日20枚まで無料で学習可能

## カード構成（計340枚）

| ファイル | 科目 | 枚数 | 内容 |
|---|---|---|---|
| `deck-kizai.json` | 器具・材料 | 120 | 電線・ケーブル種別、工具、測定器、スイッチ・コンセント、遮断器・開閉器、配管材料、端子・接続材料 |
| `deck-zumen.json` | 図記号・複線図 | 110 | 配線図記号（照明・スイッチ／コンセント・機器）、配線・系統図の基礎、複線図の基本手順、複線図（3路・4路スイッチ）、欠陥判定 |
| `deck-houki.json` | 法令・理論 | 110 | 電気工事士法、電気事業法・電気用品安全法、オームの法則・電力、配線設計（許容電流・幹線）、接地工事、電気安全のその他基礎 |

カードのスキーマ（`id` / `subject` / `topic` / `question` / `answer` / `choices` / `hintImage` / `goro` / `goroNote` / `source` / `tags`）は共通仕様に準拠。`choices` は誤答3つ（正解は含まない）、`hintImage.template` は既存15種テンプレ（`signboard` / `gradeBadge` / `structure` / `calendar` / `distance` など）から選定している。

**内容の正確性について**: 確立していて変わらない基礎知識（電線の許容電流表、オームの法則、工具・器具の名称、JIS図記号など）を中心に収録し、特定年度の技能試験候補問題番号に依存する内容や、断定できない数値・条文番号は記載していない。各カードの `source` に根拠（JIS規格番号・法令名など）を明記している。

## 技術構成

- SwiftUI / SwiftData / StoreKit2
- iOS 17.0+ / iPhone専用
- `xcodegen` でプロジェクト生成（`project.yml` が正）

## セットアップ

```bash
xcodegen generate
xcodebuild build -scheme Denko2Card -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO
```

## デッキの自己検証

```bash
python3 production/validate_deck.py
```

以下を検証する:

- 全デッキJSONがパースできる
- `id` が全ファイル横断で重複ゼロ
- 各カードの `choices` が3件（正解と重複なし）
- `hintImage.template` が既存15種テンプレ（別名込み）のいずれか
- カード総数が340枚 ±10%以内
- 必須フィールドの欠落がない

## 本アプリについて

Otsu4Card（乙種第4類危険物取扱者 暗記カード）の学習エンジンを複製・転用して作成。学習方式・課金方式は共通仕様に準拠しつつ、内容は第二種電気工事士向けに全面的に書き下ろしている。
